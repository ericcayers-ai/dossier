# Direction (P3)

**Reading this as:** a *workbench* for one person's job search, for an owner who works in it
daily, with a **light-table / printed dossier** language (ink on tinted paper, hairline rules,
serif prose, mono figures and paths), leaning toward **quiet, dense, keyboard-first**.

Name: **Light table, two rows.**

Three choices that could only belong to this product:

1. **The accent is a backlight, not a brand colour.** `--signal` is used for selection, the
   focus ring, the active tab and the filled primary — never as decoration. The one warm token
   (`--stale`) means "this artifact is older than its source", which is a fact about the
   workbench, not a mood.
2. **The navigation is a place, then a tab.** Five areas name what you are doing (Files,
   Search, Papers, Housekeeping, Agent); the pane names where you are. That is the shape of
   the workflow the manifest already encodes (capture → identity → build/verify → track), so
   the UI and the contract agree.
3. **A document footer, not a status bar.** The bottom strip reads like the foot of a printed
   page: connection, save state, path, and the two keyboard hints that change the layout.

Deliberately cut: a third type family, a second accent hue, any scroll animation, a dashboard
grid of tiles, cards inside cards, and a marketing-style hero on the empty workspace. The
empty state is an instruction ("Put the folder on the light table"), not a pitch.
