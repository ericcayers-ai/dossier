# Dossier React UI — skills audit (source-level)

**Scope.** `ui/src/**/*.tsx`, `ui/src/*.css`, `ui/src/trajectory/*.css`, plus `ui/index.html` (viewport/lang/meta), `ui/package.json` and `ui/src/lib/{api,copy}.ts` where a UI rule depends on them. No repo file was modified; every command was read-only (`cat`, `grep`, `find`, `wc`, `sed -n`, one Python contrast calculation).

**Skills read in full:** better-accessibility, better-colors, better-interface, better-layout, better-typography, better-ui, better-writing, web-quality-skills (hub only — its members are not installed here), visual-verification-receipts, interface-review, review-animations. Rules that need a tool this repo does not have (Playwright spec runner, Lighthouse, motion library) are marked `not-applicable`; rules that a browser would settle are marked `not-checkable` with the missing measurement named.

**How the contrast numbers were obtained.** `tokens.css` declares colours in `oklch()`. I converted each declared triple OKLab→linear-sRGB→sRGB→WCAG relative luminance in a Python script run this session and divided luminance pairs. The outputs track the ratios already written in the token comments to within 0.1 (`--signal-ink` computed 5.28:1 on sheet, the comment says 5.36:1), so the measurement path is sound. Rendered contrast over `color-mix()`, `::selection` or an image was **not** measured.
