## 2. Scraping as it was before this session

- **Only public JSON feeds.** `feeds.py` had six adapters and a `Prohibited` wrapper, but **no
  caller anywhere** — no CLI verb, no route, no test that fetched. `GET /api/jobs/feeds` only
  displayed the table. The `source-policy` gate was enforced inside a code path nothing reached.
- **No browser automation of any kind.** No Playwright, no headless Chromium, no cookie jar, no
  session, no recipe. "Scraping" was: a user manually saves a `job-posting-*.md`, or nothing.
- **A policy table** (`engine/sources.py`) refusing LinkedIn/Glassdoor, manual-only for
  Indeed/Seek/Workday, overridable per workspace with `.dossier/sources.json`.
- **Ingestion safety** already existed: `sanitize()` strips HTML comments, invisible characters,
  hidden styling and instruction-shaped text, and `coverage()` refuses to call a partial capture
  exhaustive.

## 3. Authentication support before this session

- The local API: one per-run bearer token, accepted three ways; `httponly` cookie set by `GET /`.
- The outbound model path: env/.dossier config, key read at call time, never stored, fail-closed.
- **No board authentication at all.** No session store, no sign-in flow, no cookie persistence.

## 4. Frontend

Verified: every pane is mounted from one switch (`ui/src/App.tsx:379-401`); every `/api` literal in
`ui/src/lib/api.ts` resolves to a real route; the import graph is closed (the files staged as
deleted are no longer referenced). Design system is `tokens.css` (OKLCH colour, six type sizes,
`4px` radius on controls only, `120ms` motion, reduced-motion and print blocks) — no spacing scale.

Gaps found:
1. `ui/dist` and `ui/node_modules` are absent, so `GET /` serves the literal
   `"<h1>Dossier</h1><p>Build ui/ first.</p>"` (`api/app.py:94-102`) and `/favicon.svg` 404s.
   **Being fixed this session by building the app** (see §8).
2. Zero frontend tests and no linter; three `eslint-disable` comments for a linter that is not
   installed.
3. `lib/api.ts:40` appends `?token=` to image/iframe/anchor/EventSource URLs, so the bearer token
   lands in DOM attributes, copy-link and browser history. The cookie path makes this redundant.
4. `/api/agent/route`, `/api/agent/next` and `POST /api/agent/ask` have no UI caller.
5. Type-only imports written as value imports; `any` at the API boundary (`lib/api.ts:122-124`).

## 5. Backend, storage and integrations

- Schema `db.py:10-11`: `files` + `files_stem` + FTS5 `files_fts`. One connection shared by the
  watch task and every request. **No `busy_timeout`** — fixed this session (5 s).
- `db.index_path` hashed every file **before** the mtime+size check, so a crawl re-read the whole
  workspace even when nothing moved — fixed this session (cheap check first).
- `db.search` passed the user's string straight into FTS5 `MATCH`. Measured: `"hello` → "unterminated
  string", `a:b` → "no such column", `*` → syntax error; `/api/search` had no handler, so a quote
  typist got **HTTP 500**. Fixed this session (quoted terms, capped at 32, error → empty list).
- `agent/loop.commit` stored `handback["mode"]` verbatim even though `next_unit` reads history
  back. Fixed this session (mode must be declared).
- `engine/doctor.py` never reported the model path although `model.availability()` is documented as
  safe for it; the only way to learn the outbound path was down was a 503. Fixed this session.
- `cli._serve` printed `?token=<bearer>` into the console. Fixed this session (bare URL; the
  cookie from `GET /` carries the auth — test added).
- `actions.py` runs argv-only with `shell=False` and cwd pinned inside the root; `POST /api/actions`
  launches a process without confirmation for the two shipped non-writing actions.
- `feeds.py` adapters were unreachable (§2). Wired this session to `dossier feeds`.
- Four rules are implemented twice (stale-render ×3, Applied date ×2, corpus ×2, role
  classification ×2) and the last pair already disagrees. **Not touched** — each needs an owner
  decision, not a drive-by edit.
- `.dossier/tree.json` holds user-authored DAG nodes in a git-ignored folder the docs call derived.

## 6. What was missing for automated research

Named plainly, because these are the things the new system had to supply: a caller for the feed
layer; a browser engine choice; a session that survives a run; dynamic-page rendering; a
maintainable per-board workflow; pacing; failure classification with retries that stop at a refusal;
deduplication and resumability; provenance per capture; and a report that distinguishes "complete"
from "exited zero".
