# Dossier — implementation plan

> **For the implementing agent:** execute task-by-task, in order. Each task ends with a runnable check and a commit. Steps use `- [ ]` for tracking. Read `DESIGN.md` in this folder first — it is the source of truth for colour, type, layout, copy, and product principles.

**Goal:** a local-first Windows app that explores, views, edits, exports, and acts on a mixed document folder (docx / pdf / md / json / csv / py / png), with a Bundle Rail that keeps related files together.

**Architecture:** one FastAPI process bound to `127.0.0.1` on a random free port with a per-launch bearer token; it serves a pre-built React bundle and a root-confined filesystem/action API. A SQLite database (WAL + FTS5) caches file metadata and extracted text; `watchfiles` keeps it current in a background task. All document work happens in Python (PyMuPDF, python-docx, docx2pdf); the browser only renders.

**Tech stack:** Python 3.13.15 (`python3` / `py -3.13` — **not** bare `python`, which is 3.11 and lacks openpyxl/pandas/pdfplumber), FastAPI, Uvicorn, watchfiles, SQLite FTS5, PyMuPDF, python-docx, docx2pdf, pypdf, Pillow · React 19 + Vite 8 (Node v24.19.0), CodeMirror 6, AG Grid Community, pdfjs-dist.

## Global constraints

- **Disk budget: 35.8 GB free on C:.** No Electron, no Monaco, no Chromium download, no LibreOffice install as a prerequisite. `node_modules` must stay under 400 MB and be deletable after `npm run build`.
- **Interpreter:** every Python entry point runs under `py -3.13`. Pass **native Windows paths** (`<windows-user>/...`) to Python, never MSYS `/c/...` — python-docx raises `PackageNotFoundError` on the latter even though `ls` works.
- **Terminal parser on this host blocks nested `$( )` inside quotes and multi-line heredocs.** Write files with the file tools; run simple sequential commands.
- **Bind `127.0.0.1` only.** Every API request requires `Authorization: Bearer <token>` from the launch token; reject `Origin` headers that aren't the app's own.
- **Root confinement:** every path from the client is `Path(root, rel).resolve()` and must satisfy `is_relative_to(root)` after resolution. Reject symlinks that escape. No absolute paths accepted from the client, ever.
- **No hard delete.** Overwrites and deletes copy the prior file to `.dossier/trash/<ISO8601>/<relpath>` first.
- **Writes are conditional.** Every save sends the `mtime_ns` + `sha256` the client loaded; the server refuses with `409` if the file changed underneath. This is non-negotiable — another agent session is actively writing into the proving-ground folder.
- **Word is single-threaded.** All `docx2pdf` work runs in one serialized worker with a 120s timeout; concurrent COM calls corrupt output.
- **Colour/type/layout tokens come from `DESIGN.md`.** Do not invent new ones. No cream backgrounds, no gradient text, no glassmorphism, no numbered section eyebrows, no identical-card grids.
- **Every claim of "done" needs a receipt:** the exact command and its output line.

**Proving-ground folder (read-mostly, do not mutate during development):**
`<resume-corpus-root>` — 374 files / 22.9 MB; 108 json, 85 pdf, 73 md, 62 docx, 37 png, 5 py, 2 csv, 1 zip.

Schema:
```sql
CREATE TABLE files(
  rel TEXT PRIMARY KEY, ext TEXT, size INTEGER, mtime_ns INTEGER,
  sha256 TEXT, kind TEXT, stem_key TEXT, role TEXT,
  meta_json TEXT, indexed_at INTEGER, extract_error TEXT
);
CREATE INDEX files_stem ON files(stem_key);
CREATE VIRTUAL TABLE files_fts USING fts5(rel UNINDEXED, body, tokenize='unicode61');
```
